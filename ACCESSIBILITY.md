# Accessibility

Target: WCAG 2.2 AA. The shell includes a skip link, semantic landmarks, keyboard-focus indicators, labeled controls, dialog semantics, table headers/captions, text severity/status labels, reduced-motion support, and responsive navigation. Critical Playwright coverage runs axe against the authenticated dashboard. Color is supplementary: severity and status are always written as text or symbol plus text.

Manual release checks: keyboard-only login and navigation, 200% zoom, screen-reader form errors and live state updates, light/dark contrast, mobile drawer focus, print output, and map alternative operational lists.
