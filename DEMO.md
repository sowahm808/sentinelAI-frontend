# Demonstration guide

1. Start the app and use the credentials in `README.md`.
2. Review operational summary and layered map on **Overview**.
3. Create an incident from **Incidents → Create incident**; incomplete drafts survive a refresh in the current tab.
4. Open the Lewisville Tornado command workspace.
5. Review the persistent AI disclaimer, generate the deterministic response plan, and explicitly approve one recommendation.
6. Assign a resource with the confirmation dialog.
7. Request an AI-assisted alert draft, edit it, and submit it for approval. Sending is simulated.
8. Generate a Situation Report and use browser Print / Save PDF.
9. Sign out through the JL menu.

Seeded content includes two incidents, six hospitals, eight shelters, twenty resources, five displayed road closures, three weather alerts, timeline activity, and one response plan. Every operational value is synthetic.
